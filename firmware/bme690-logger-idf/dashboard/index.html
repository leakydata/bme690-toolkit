Sensors

The shuttle board has eight BME690 gas sensors, printed U1 to U8. The board software counts them from 0, so U1 is "sensor 0". Tap a sensor for details.

Use after fixing a wire.

Wiring reference

Rows in red belong to sensors that are not working. If every sensor fails, check the shared wires first: power, ground, SCK, SDO and SDI.

Gas resistance

Each sensor heats itself through 10 temperatures in turn and its resistance jumps at every step. Pick one step for a smooth trend, or "All steps" for the whole zig-zag. Lower resistance usually means more gas. Log scale.

    Heater-step fingerprint

    Gas resistance at each of the 10 heater steps: latest complete cycle solid, the one before dashed. A healthy sensor repeats the same shape every cycle, highest at the coolest steps. Flat, empty or jumping bars point to a problem.

    Current label
    –

    Each label becomes a separate sample ("specimen") in AI-Studio. Press Next sample whenever you change what the sensors are smelling. The BOOT button on the board does the same.

    Label names

    Saving also makes this the current label, so new readings are tagged with it.

    SD card

    Getting data into BME AI-Studio: take the card out (or download the files on the Files tab), then in AI-Studio use Import on any one chunk. The other chunks of that session are picked up automatically as long as they stay in the same folder.

    Burn-in for new sensors

    –

    Factory-new sensors drift for their first hours. Bosch recommend at least 12 hours on their stabilization profile (HP-001, 320 °C) before collecting data to train on. The board records the burn-in under the label "burn-in" and switches back to your heater profile by itself when it ends. Keep it in clean, still air.

    Heater profile

    –

    Design heater profiles in BME AI-Studio (board type BME690 8x Shuttle board), save the board configuration, and upload the .bmeconfig file here. The board checks it, keeps it on the SD card and uses it from then on. A recording in progress ends and a new session starts, because each recording holds one configuration.

    Recordings on the card

    A session (e.g. s0007) is split into 15-minute chunks. Keep every .bmelabelinfo file next to its .bmerawdata file with the same name, or AI-Studio loses the label names. If a download does nothing, open http://192.168.4.1 in your normal browser instead of the WiFi sign-in window.

    Firmware

    –

    To update: while you are on the internet, download bme690-logger-app.bin from leakydata.github.io/bme690-toolkit (Firmware section). Then come back to this page and choose the file here. The board checks it, installs it and restarts; if the new version fails to start, the board goes back to this one by itself.

    Record in this browser

    No SD card needed: this page collects the live readings and gives you a .bmerawdata file (plus .bmelabelinfo) for AI-Studio. Keep the page open and the screen on; if the phone sleeps or WiFi drops, readings are missed.
