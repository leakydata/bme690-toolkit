BME690 Logger installer

Put the logger firmware on an ESP32-S3 DevKitC straight from this page. It runs a Bosch BME690 8x shuttle board without an Application Board: it records all eight sensors to a microSD card as BME AI-Studio files and shows live graphs on its own WiFi network. You don't need to install anything.

1

Plug in the board

Connect the ESP32-S3 DevKitC to this computer with a USB-C cable that carries data (some cables only charge). The board has two USB-C ports; either works. The one labelled USB needs no driver on any system.

Wire the shuttle before or after installing, it doesn't matter. The wiring table is further down.

2

Install

Click the button, pick the board's port from the list, and confirm. It takes about a minute. Choose Erase if you're asked; it removes whatever was on the board before.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer (Windows, macOS or Linux). Phones, Firefox and Safari can't install firmware.
Installing needs a secure page. Open it at its https:// address.

3

Open the dashboard

After installing, press the board's RST button. On your phone or laptop, join the WiFi network BME690-XXXX (no password). The dashboard opens by itself. If it doesn't, go to http://192.168.4.1.

Its Health tab checks every sensor and tells you in plain English which wire to look at if one isn't answering.

Already installed? Update over WiFi

Boards running version 2.1 or later can update without a cable. Download the firmware file while you're online, join the board's WiFi, and choose the file in the dashboard under Files → Firmware. If the new version doesn't start properly, the board returns to the old one by itself.

Download bme690-logger-app.bin

Boards on an older version need one install with the button above first; it sets up the room for over-the-air updates.

Then: BME Studio

Import the board's recordings, see what the sensors smell, and train a model that tells samples apart, all in your browser. It also opens BME AI-Studio projects and exports files AI-Studio can import.

Wiring

A diagram with the DevKitC header pin for every wire is in the wiring guide.

The shuttle's P1 row has 7 pins and P2 has 9, at 1.27 mm pitch. Pin 1 of each row is marked on the board. Never connect 5V to the shuttle.

If something goes wrong

The board isn't in the list of ports

Try a different cable first, because many only charge. Then try the board's other USB port. On Windows or macOS, the port labelled UART needs the CH340 or CP210x driver, whichever chip your board has; the port labelled USB never does. On Linux, if the port appears but won't open, add yourself to the dialout group and log in again.

It hangs on "Connecting" or fails partway

Put the board in download mode by hand: hold BOOT, press and release RST, then release BOOT. Click Install again. Close any other program using the port, such as the Arduino serial monitor.

The WiFi network doesn't appear

Press RST once after installing. The network is called BME690- followed by four characters, and it only works on 2.4 GHz WiFi, which every phone supports.

I want to see what the board is doing

Click Install again and choose Logs & Console. The board prints its sensor check at start-up; type help for its commands.
